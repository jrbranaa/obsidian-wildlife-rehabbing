## Use

Pain and inflammation — fractures, soft-tissue injury, post-trauma, and
adjunct pain control alongside antibiotics (e.g. Cass's jaw injury,
[[Head Injury]] cases).

## Dosing — two protocols on file

### SWR chart (May 2026) — current default

- **1 mg/kg**, PO, **BID for 1–3 days**.
- Standard-strength **1.5 mg/mL** for patients roughly **≥200 g**.
- For smaller patients, use the **Metacam 1:10 dilution** (below) instead of
  the standard strength — it exists specifically so small-volume doses stay
  measurable/accurate.
- **Ensure the animal is well hydrated** before and during the course.

#### Dose from weight (at 1.5 mg/mL, 1 mg/kg, per SWR chart — roughly ≥200 g)

| Weight | Dose |
| ------ | ---- |
| 200 g  | 0.13 mL |
| 300 g  | 0.20 mL |
| 500 g  | 0.33 mL |
| 1000 g | 0.67 mL |

### Metacam 1:10 dilution — for smaller patients (per SWR chart)

- Same **1 mg/kg** dose, but using meloxicam **diluted 1:10** to **0.15 mg/mL**
  so the volume is large enough to measure precisely in small patients.
- Chart provides values from 10 g up to 300 g; ensure the animal is well
  hydrated.

#### Dose from weight (at 0.15 mg/mL diluted, 1 mg/kg, per SWR chart — roughly ≤300 g)

| ------ | ---- |
| 50 g   | 0.33 mL |
| 100 g  | 0.67 mL |
| 200 g  | 1.33 mL |
| 300 g  | 2.00 mL |

## Cautions

- Do not combine with corticosteroids ([[Dexamethasone]]).
- Avoid in dehydrated, hypothermic, or shocky patients until stabilized.
- Avoid with known renal/GI compromise.
- Given the two dose ranges on file differ substantially, **don't average
  or split the difference** — pick one protocol deliberately, per your vet's
  guidance, and note in the patient's file which one is being used.
