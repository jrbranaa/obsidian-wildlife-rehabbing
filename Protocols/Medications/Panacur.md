## Use

Removal of **ascarids, hookworms, and stomach worms**. Broader parasite
coverage than [[Strongid]]. Per the manual: worms are **not a common
problem** in squirrels — rule out other causes (diet, coccidia) before
treating for worms.

## Dosing

- **20 mg/kg**, PO, SID, for **3 days**.
- Formulation: **100 mg/mL**.
- Evaluate response at **3 days**.

### Dose from weight (at 100 mg/mL, 20 mg/kg)

| Weight | Dose |
| ------ | ---- |
| 50 g   | 0.01 mL |
| 100 g  | 0.02 mL |
| 200 g  | 0.04 mL |
| 300 g  | 0.06 mL |
| 500 g  | 0.10 mL |
| 1000 g | 0.20 mL |

## Cautions

- Confirm worms are actually the cause before treating — coccidia ([[Baycox]]/
  [[Albon]]) is far more common in juvenile squirrels with diarrhea than true
  worm infestation.

## History

Log each dose in the patient's **## Medications** table (drug = `Panacur`).
