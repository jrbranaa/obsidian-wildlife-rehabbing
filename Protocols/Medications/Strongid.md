## Use

Removal of **ascarids, hookworms, and stomach worms**. Similar to [[Panacur]]
but covers fewer parasite types.

## Dosing

- Dosed as a simple **volume-per-body-weight factor**: **0.0028 mL per gram**
  of body weight (not a standard mg/kg + concentration calculation — this is
  how the source chart expresses it directly).
- **One dose, then a second dose in 2 weeks.**

### Dose from weight (0.0028 mL/g)

| Weight | Dose |
| ------ | ---- |
| 50 g   | 0.14 mL |
| 100 g  | 0.28 mL |
| 200 g  | 0.56 mL |
| 300 g  | 0.84 mL |
| 500 g  | 1.40 mL |
| 1000 g | 2.80 mL |

## Cautions

- Narrower parasite coverage than Panacur — prefer Panacur if unsure which
  parasite is present.

## History

Log each dose in the patient's **## Medications** table (drug = `Strongid`).
